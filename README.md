# QuoteCraft Studio — Contact Hub & Live Interactive Demos

Fast, mobile-first conversion landing pages, interactive quote/cost calculators, and serverless workflow tools engineered for US high-ticket service businesses on `$0/mo` edge hosting with 100% code ownership.

## Contents

- `/` ([`index.html`](./index.html)) — QuoteCraft Studio Mini Contact Hub (booking, direct email, zero-backend 30-sec project brief modal, and filterable live demo directory).
- `/demos/roof-calculator/` ([`demos/roof-calculator/index.html`](./demos/roof-calculator/index.html)) — **Live Interactive Demo #1: US Roof Replacement Quote Calculator** (square footage & roofing squares math, pitch slope & waste factor, 5 US material tiers, tear-off/upgrade options, 120-month financing preview, and zero-backend lead capture).

## Architecture Principles

- **Zero External CDN Dependencies:** Self-contained HTML5, CSS3, and Vanilla JavaScript for sub-second mobile load times.
- **`$0/mo` Static & Serverless Hosting:** Ready for Cloudflare Pages or GitHub Pages auto-deploy directly from `main`.
- **Single-Block Configuration:** Controlled centrally via `STUDIO_CONFIG` (`index.html`) and `CALCULATOR_CONFIG` (`demos/roof-calculator/index.html`).
